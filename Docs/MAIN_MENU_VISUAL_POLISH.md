# Главное меню: визуальный polish (задача #110)

Этот пакет сохраняет три опорных элемента стиля City Highways:
**золотой логотип, пиксельный город и красную «Новую игру»**.
Обновления не меняют игровую механику, настройки игроков или Steam-интеграцию.

## Компоновка

Основные действия на центральной колонке:

1. **Новая игра** — красная кнопка, открывает экран настройки партии.
2. **Играть сразу** — отдельная компактная кнопка; как старый «Быстрый старт»,
   действительно вызывает `StartGame` с текущими параметрами (без окна настройки).
3. **Обучение** — с компактным переходом **Правила** непосредственно ниже.
4. **Сетевая игра** — с переходом **Клубы и друзья** непосредственно ниже.

Статистика перенесена к карточке активного профиля: имя и аватар
подтягиваются динамически, «Влад» не захардкожен. Настройки и язык
перенесены в поповер шестерёнки справа сверху. Поповер закрывается
при навигации, Escape / кнопке «Назад» геймпада и при открытии уведомлений.
Оба пункта остаются доступны клавиатурой и контроллером.

## Визуальный фон и дорога

- `MenuLegibilityVeil` создаёт мягкое центральное затемнение за
  подписями; окна домов по бокам остаются яркими, нижнее шоссе не тускнеет.
- `MenuHighwayOverlay` показывает две полосы пиксельных автомобилей,
  разметку, видимый съезд и небольшой светофор. Работает поверх обоих
  вариантов фона: живого `MenuBackground` и `GeneratedArt.KeyArt`.
  Это чистая геометрия `ColorMesh` без новых ассетов и текстур.
- При нажатии **«Новая игра»** загорается зелёный сигнал, а выделенная
  машина за 0,85 секунды поворачивает с шоссе в город.
  После завершения анимации открываются существующие настройки партии.
  Повторное нажатие не запускает несколько переходов. Если пользователь
  успел перейти в другой раздел, ожидающий переход отменяется.
- Режим **уменьшенной анимации** открывает настройки сразу;
  движение обычного потока автомобилей в этом режиме отключено.
  События от декоративных элементов не перехватывают ввод.

## Ручная проверка перед merge

- [ ] Запустить главное меню в RU и EN. Сверить переходы всех действий,
      включая «Правила», «Клубы и друзья», статистику профиля и язык.
- [ ] Проверить, что «Новая игра» красная, золотой логотип и город сохранены.
- [ ] Нажать «Новая игра»: зелёный сигнал, одна машина сворачивает в город,
      затем появляется экран настройки; два быстрых нажатия дают один переход.
- [ ] Проверить «Играть сразу»: открывается сама партия без окна параметров.
- [ ] Проверить свет меню: день/ночь и все три палитры; картинки KeyArt вкл/выкл.
      Пиксельные машины видны в обоих режимах, центральные подписи читаемы.
- [ ] Открыть шестерёнку мышью, Enter/Space и геймпадом.
      Убедиться, что Escape/Back закрывает её, не вызывая другого экрана;
      уведомления и шестерёнка не перекрывают друг друга.
- [ ] Включить Reduced Motion: кнопка «Новая игра» должна работать без задержки,
      движение новых пиксельных машин должно остановиться.
- [ ] Проверить Steam Deck (1280×800), 1920×1080 и оконный режим,
      в том числе английские длинные строки.

## Автоматическая регрессия

`MenuRoadDepartureTests` и `MenuLegibilityVeilTests` проверяют траекторию,
тайминг, работу с разрешениями, градиент и reduced motion.
`Tools/main_menu_polish.test.mjs` фиксирует связи навигации,
сохранённые цветовые акценты, локализацию и интеграцию анимации.
Для изменений меню автоматически запускается отдельный
`Main menu visual regression guard` (Node.js 24), кроме общего Unity Edit Mode.

Не смешивать этот UI PR со стабилизацией replay или серверными миграциями;
в основную ветку объединять только после успешных проверок на конкретном HEAD.
