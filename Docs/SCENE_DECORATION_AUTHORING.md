# Scene-authored 3D decorations (stage 1.5)

This is an **additive visual layer** for procedural 3D cities. It does **not** replace CityPlanner or change Core maps, save files, roads or game rules.

## Add a decoration

1. Open `Assets/CityHighways/Scenes/CityHighways.unity` in Unity.
2. Add a simple visual Prefab to your project using the usual Unity workflow. The repository does not yet ship example decoration prefabs.
3. In the Hierarchy choose **GameObject → City Highways → Decoration Anchor**.
4. In the anchor Inspector set **Map Name** to the exact `CityMap.Name` (for example `Москва`, `Амстердам` or `Чунцин`); assign **Visual Prefab** and enable **Show In Game**.
5. Move/rotate/scale the anchor in Scene View. The outlined Gizmo is its placement guide; the Prefab itself is instantiated during a 3D game.
6. Save the scene and commit the scene, Prefab and their `.meta` files. In Play Mode start a game on the matching map with 3D rendering enabled.

## Runtime behavior

- `City3DScene.Build` calls `SceneDecorationSpawner.Spawn` after creating the procedural city. Only active, enabled anchors matching the map name and holding a non-null Prefab are used.
- Prefabs are instantiated under the generated city root, at the authoring anchor's world position and rotation; their scale follows the anchor's scale. The generated city root owns cleanup on exit.
- Existing roads, gameplay nodes and buildings remain generated by code. Authored decorations may overlap procedural buildings; use Scene View and Play Mode to inspect.
- Decorations are **not rendered in 2D mode** and are **not part of game saves or replay state**. Keep them non-interactive and visual-only.
- The startup scene still uses a dynamically constructed UI. Decoration anchors are not a replacement for Unity UI Toolkit UXML assets.
