# Stage 4 — campaign v1

Twelve missions on Moscow, Amsterdam and Chongqing, fixed seeds, one human seat and smart bots. Competitive missions use victory plus optional contract/bridge/road-piece targets; co-op missions require team victory plus optional crisis cap. Each mission is unlocked by completing the preceding one. These initial objectives/seeds are design hypotheses, not verified human win rates.

Entry: New Game → Campaign (preserves existing six home actions). Separate per-profile campaign progress and checkpoint using hashed owner paths, stable local GUID or Steam ID. Atomic writes use existing ReplayStorageIO. Campaign setup carries mission/owner so saves resume without changing ordinary settings; ordinary checkpoint stays separate. A pending campaign checkpoint must be resumed or explicitly discarded before starting another mission. Completion only advances the contiguous prefix and is idempotent. If progress write fails, retain checkpoint and offer retry on results. Campaign does not award ordinary profile currency, achievements, stats, replay or cloud record submission. Progress is local-only; no cloud sync or new server. Existing normal play unchanged except safer atomic classic save replacement.

16 new Edit Mode cases covering catalog, sequence, all 12 setups, map construction, profile key isolation, RU/EN labels. Manual QA: compact menu, all twelve human playthroughs, save/restart/resume, switch profile, discard, loss/retry, progress-write error, ordinary save isolation, campaign result screen. Bot/human balancing and story cutscenes not included.
