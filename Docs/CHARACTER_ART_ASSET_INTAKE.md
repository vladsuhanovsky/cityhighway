### Local import troubleshooting

If Load / Reload cannot find the model, select M02 or F01 and the correct format, then **Choose local file...** and select the extracted GLB/FBX. The tool copies only the selected file to its exact ignored path, after explicit confirmation; it never replaces existing files or deletes sources. **Reimport** forces a synchronous Unity asset import. **Show asset in Project** reveals the imported asset in the Inspector. Diagnostics distinguish missing disk file, malformed GLB header, missing imported GameObject (with importer and main asset type), and invalid/inactive model root. GLB header preflight does not certify mesh or importer compatibility. Check Console for import failures. Imported art remains local; no new dependencies or runtime changes.

## Modular wardrobe foundation — segmented body coverage

Existing 58 IDs and seven slots remain canonical; no catalog edits, purchases or save changes. Optional ProfileBodyCoverage on the same root as ProfileAvatarRig uses authored RegionBinding (body ID, single region, skinned renderer) and ItemCoverage (existing non-body item ID, region flags). Scalp, torso, upper arms, forearms, pelvis, thighs, calves and feet are supported. Each covered region must have a segment on every bound body variant. Multiple renderers per region are allowed, but a renderer cannot be registered twice or represent multiple regions. Bones/root bone must be persistent descendants of the rig and outside switchable visual roots. Only visible item IDs contribute to the union of masks; all managed renderers are set on each application, so a hidden/removed item restores skin unless another visible item covers it. Unmanaged renderers are unchanged. Invalid coverage or missing outfit bindings reject the whole application before changing visibility. Existing rigs without coverage retain the same behavior; production Humanoid validation permits this one additional authored component on the root.

This mechanism does not automatically segment geometry or detect garment intersections. Each authored region must be wholly covered by the applicable garment; leave face, neck, hands and exposed sections outside masks. A renderer spanning a covered and exposed area must first be split or assigned a finer authored solution, not hidden wholesale. The V8 fixed outfit cannot be registered as a complete modular rig: body includes baked hair/shirt and masked lower body. Actual candidate mapping from V8: hat_hardhat / hat_f_hardhat; top_vest / top_f_vest (requires independent undershirt); bottom_trousers / bottom_f_trousers; shoes_boots / shoes_f_boots (pair under one root); acc_radio / acc_f_radio. These are candidate mappings, not installed bindings. Reconstruct unmasked base from original licensed source, separate hair and shirt, author coverage per garment and check all skin tones, seams, animation and mixed outfits. Do not fabricate missing assets or aliases for other IDs. Public CI tests synthetic coverage and state transitions only. V8 podium/radio visual acceptance remains open; Humanoid clip conversion remains open.
