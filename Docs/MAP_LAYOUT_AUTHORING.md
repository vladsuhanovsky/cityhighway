# Редактирование расположения карты в Unity — первый шаг

Этот редактор работает с **логическими точками карты** (станции, площади, перекрёстки), уже заданными в JSON. Это не редактор процедурных зданий, деревьев, рельефа или UI.

## Использование

1. Откройте `Assets/CityHighways/Scenes/CityHighways.unity`.
2. В меню выберите **City Highways → Map Layout → 1. Import Moscow markers**.
3. В Hierarchy появится `Map Layout Preview - moscow`. Его дочерние объекты — точки, а голубые линии Gizmos — дороги.
4. Выделите дочерний маркер и измените его **Transform Position** инструментом Move (W) в Scene View. Разрешено перемещение по X/Z. Высота Y не используется экспортом.
5. Выберите корень или дочерний маркер и выполните **City Highways → Map Layout → 2. Export selected preview to JSON**.
6. Подтвердите экспорт. Он обновит **только координаты `locations[].x` и `locations[].y`** в `moscow.json`, сохраняя остальные разделы исходного JSON.
7. Проверьте Git diff, затем запустите игру и тесты. Если расположение не подходит, откатите изменение файла JSON в Git.

**Внимание:** сцена содержит лишь визуальные маркеры для редактирования. Runtime-игра по-прежнему загружает JSON-карту. Изменение Transform без экспорта не меняет игру. Перемещение точек может менять визуальные маршруты и геометрию; проверяйте карту вручную.

## Ограничения первой версии

- Команда импорта создаёт маркеры для **Москвы**. Для других карт потребуется отдельная команда выбора источника.
- Один активный preview на сцену; повторный импорт не перезаписывает существующие правки.
- Экспорт проверяет непустые и уникальные ID маркеров, количество точек и диапазон координат [0,1]; он не позволяет добавлять или удалять дороги/точки.
- Экспорт работает только с JSON в `Assets/CityHighways/Resources/CityHighways/Maps/`. Не изменяет контракты, длины дорог, ресурсы и правила.
- Карта визуально строится в масштабе **14 × 7.8 единиц Unity**, по оси X/Z. Это плоская схема точек, не полный 3D-город.
- Карта и её состояние во время партии остаются источником истины для логики игры. Визуальные маркеры для редактирования не участвуют в сохранениях.
- Если нужно редактировать саму геометрию зданий, их Prefabs и настройки 3D, это следующая самостоятельная миграция.

- [ ] Открыть сцену и убедиться, что новые скрипты компилируются и нет Missing Script.
- [ ] Импортировать московские точки и увидеть линии дорог.
- [ ] Сдвинуть одну точку, экспортировать координаты и проверить diff: изменились только два числовых поля выбранной точки.
- [ ] Повторно импортировать после удаления preview и проверить новое положение.
- [ ] Запустить Play Mode и убедиться, что карта отображает изменённое положение, основные игровые действия проходят.
- [ ] Проверить откат JSON через Git, прохождение Edit Mode suite и локализационного аудита.
