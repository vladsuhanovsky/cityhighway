# City Highways — Interface Editor

## Для чего нужен

**City Highways → UI → Interface Editor** — окно Unity Editor для настройки
общего визуального оформления и части размеров отдельных экранов без
изменения C#. Настройки сохраняются в обычных Unity ScriptableObject-ассетах
и могут коммититься вместе с проектом.

> Это **редактор параметров и схематичный предпросмотр**, а не полный
> UI Builder / WYSIWYG-редактор со свободным перетаскиванием элементов.
> Изменения нужно проверять в Game View / Play Mode.

## Как пользоваться

1. Открой проект Unity и дождись компиляции.
2. В верхнем меню выбери **City Highways → UI → Interface Editor**.
3. Выбери вкладку нужного экрана.
4. Измени цвета или размеры в левой колонке.
5. Справа проверь примерное сочетание цветов и пропорций.
6. Нажми **Save style assets**. При желании — **Select style asset in Inspector**.
7. Открой игровое меню или игровую сцену в Play Mode (для точной проверки
   изменений перезапусти Play Mode): большинство экранов строятся при открытии.
8. Если правка удачна, сохрани и закоммить изменённые `.asset`-файлы.

Параметры применяются при создании нового экранного элемента, поэтому
редактирование стиля **не гарантирует живое изменение уже открытого экрана**.
Для основного workflow редактируй в Edit Mode, а не в запущенной игре.

## Вкладки

| Раздел | Настраиваемые свойства |
| --- | --- |
| **Theme** | глобальные цвета фона, панелей, наведения, текста, красных и золотых акцентов, успеха, прозрачность панелей, минимальная высота общих кнопок, радиусы кнопок и карточек, отступ секций |
| **Main Menu** | существующий `MainMenuStyle`: все шесть кнопок, 4/12 px промежутки, шрифты, заголовок, новости, красный градиент, затемнение города, движение машин |
| **New Game** | ширина подсказки при выборе персонажа и карточки параметров новой партии |
| **Online** | ширина поля имени игрока и минимальная высота сетевых текстовых полей |
| **Rules** | ширина навигации, поисковой строки и высота области чтения правил |
| **Settings** | ширина списка категорий и карточки предпросмотра |
| **Stats & Profile** | высота истории статистики, ширина блока персонажей, высота области профиля и ширина панели гардероба |
| **Game HUD** | высота верхней и нижней полос, ширина выдвижной панели и панели игроков в классическом игровом экране |

**Цвета на вкладке Theme** влияют на все экраны, использующие общую
`Theme` и виджеты `Ui`. Некоторые специализированные элементы имеют
собственные цвета и пока **не** охвачены. Аналогично ширина/высота на
вкладках касается только явно подключённых полей, а не всех элементов
указанного раздела.

## Где хранятся настройки

- `Assets/CityHighways/Resources/CityHighways/UI/InterfaceTheme.asset` —
  общая тема и параметры экранов;
- `Assets/CityHighways/Resources/CityHighways/UI/MainMenuStyle.asset` —
  сохранённый ранее стиль главного меню.

Оба файла содержат стартовые значения, соответствующие предыдущему
интерфейсу: при открытии новой версии существующее меню не должно
самостоятельно изменить размеры или цвета.

Команда `City Highways → UI → Edit Main Menu Style` остаётся доступной
для прямой настройки только главного меню.

## Безопасность и контроль качества

- Значения размеров ограничены диапазонами `[Range]` в Inspector и
  дополнительно `Mathf.Clamp` при чтении из файла.
- Для повреждённых чисел NaN/Infinity используются резервные размеры.
- При отсутствии темы проект использует прежние исходные цвета и размеры.
- Editor Window использует `SerializedObject` и Unity Undo/Redo.
- Предпросмотр — приближённая схема. Реальные размеры, локализация, 
  скроллинг и навигация проверяются в Play Mode.
- Настройки не меняют игровую логику, правила, серверные контракты и
  данные сохранений.

## Минимальная ручная приёмка

- [ ] Окно открывается через `City Highways → UI → Interface Editor`;
      вкладки Theme / Main Menu / New Game / Online / Rules / Settings /
      Stats & Profile / Game HUD переключаются без ошибок.
- [ ] Общие цвета меняют вид меню и HUD после перезапуска Play Mode.
- [ ] Main Menu использует исходный `MainMenuStyle.asset`; размеры кнопок
      и анимация машин не сбрасываются.
- [ ] Новая игра: работают размер карточки и подсказка персонажа.
- [ ] Сетевая игра: проверены размеры текстовых полей и работа подключения.
- [ ] Правила: область чтения и список разделов не перекрываются.
- [ ] Настройки: навигация/предпросмотр не обрезаются.
- [ ] Статистика и профиль: прокрутка, карточки и гардероб работают.
- [ ] Игра: HUD отрисовывается с изменёнными высотами панелей.
- [ ] Русский и английский, 1920×1080, 1280×800 (Steam Deck),
      масштаб 0.9–1.3 и геймпад/клавиатура.
- [ ] После правок вернуть стандартные значения и убедиться, что
      исходный вид не изменился.

## Что оставить на отдельную будущую итерацию

Полное визуальное перемещение кнопок, изменение дерева UI,
настройка индивидуальной геометрии *каждого* игрового элемента,
перетаскивание HUD поверх живой сцены требуют расширения
архитектуры и постепенного переноса экранов в **UXML/USS + UI Builder**.
Для этого нужна отдельная задача; текущий этап добавляет полезный,
недеструктивный редактор в существующую C#-архитектуру.

После приёмки Interface Editor возвращаемся к исходному плану игры:
закрываем незавершённый технический долг этапов стабилизации,
Steam/геймпада и социальных функций, затем берём новый контент.
